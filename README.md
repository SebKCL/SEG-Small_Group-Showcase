# Team Task Manager – Django Web Application (Group Project)

> A collaborative task management web app built by a five-person team using agile software engineering practices.

🔒 **The source code is in a private repository** because this was a university group project at King's College London. I'm happy to walk through the code on request.

## Overview
The app lets users sign up, connect with friends, form teams, and create, assign and track tasks together. I was one of five developers on the team (Team Narwhal).

## Features
- User accounts: sign up, log in and out, profile editing and password change
- A friends system with friend requests, accepting and declining, and user search
- Team creation, adding members, team detail pages and team deletion
- Tasks with titles, descriptions and due dates, which can be created, edited, assigned or unassigned to team members, ticked off and deleted
- A personal dashboard and team task views
- Database seeding for development data

## Engineering practices
- A large automated test suite (forms, models and views) using Django's test framework, with coverage configuration
- A clear separation between models, forms, views, helpers and templates
- Bootstrap-based templates built from reusable partials

## Skills demonstrated
Full-stack web development · Django ORM and data modelling · authentication · automated testing · teamwork and Git collaboration

## Tech stack
Python · Django · HTML / Bootstrap · SQLite
