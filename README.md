# Team Task Manager: Django Web App (Group Project)

> Five of us built a web app where teams create, assign and track tasks together.

🔒 The code sits in a private repository because this was a King's College London group project. Ask me and I'll walk you through it.

## Overview
You sign up, add friends, form a team and share tasks with it. I was one of the five developers on Team Narwhal.

## Features
- Accounts: sign up, log in and out, edit your profile, change your password
- Friends: send, accept and decline requests, and search for users
- Teams: create a team, add members, view team pages, delete a team
- Tasks: title, description and due date; create, edit, assign, unassign, tick off and delete
- A personal dashboard and a view of each team's tasks
- A seed command that fills the database with test data

## How we built it
- Django tests cover the forms, models and views, with a coverage config
- Models, forms, views, helpers and templates each live in their own layer
- Bootstrap templates share reusable partials
